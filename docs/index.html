    Every app on its own track

    Game, Discord, Spotify, Chrome and your microphone each get their own audio track. Cut the music later and keep the game.

    Mix still holds everything, for anyone who wants one track.

    Mute a moment, not the whole track

    Shift and drag over a waveform, then mute just that stretch. The shout goes, the shot stays.

    Each track keeps its own muted parts, so the game and your voice never fight.

    Copy: no re-encode, done in seconds

    Trim and export in seconds

    Set a start and an end, then export to MKV, MP4, MP3, M4A, WAV or FLAC. Copy mode skips encoding entirely.

    Crop and colour adjustments are there too, for the clip you post.

    Hardware encoding runs on NVIDIA and AMD graphics cards, and CPU encoding always works. No brand lock in.

    Why ClipNest

    Play like nobody is recording. ClipNest already is, and one key keeps the last 90 seconds.

    Built on OBS. Recording runs on the open source engine behind OBS Studio, with instant replay, game folders and an editor built around it.

    Nothing leaves your PC. No account and no uploads. The one download is the recording engine on first launch, straight from OBS’s releases on GitHub.

    Games that hide. VALORANT and other games block normal screen capture. Games only mode records them anyway, and keeps the game in frame through Alt+Tab.

    Open source. Every line is on GitHub under GPL 2.0 or later. Read it, build it yourself, or open an issue when something breaks.
