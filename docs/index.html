Three steps and you’re recording

  1. Install itRun the setup file from the latest release. No admin rights.
  2. Add FFmpegIn the editor, go to File → FFmpeg folder → the folder with ffmpeg.exe.
  3. PlayStart replay, then press your hotkey when something happens.
