# ClipNest v1.2.0

ClipNest is a lightweight Windows instant replay and game recording app built as a simple alternative to tools like NVIDIA ShadowPlay.

## Requirements

- Windows 10 or 11
- Python 3.11+
- Dependencies listed in `requirements.txt`
- FFmpeg is included with the project

Install the required Python packages with:

```bash
pip install -r requirements.txt
```

## Launching ClipNest

The easiest way to launch ClipNest is by opening: 
```
Start_ClipNest.bat
```
a visual basic launch option is also present

## Features

- Configurable instant replay recording
- Save recent gameplay with a keyboard shortcut
- Normal start/stop recording while instant replay remains active
- Automatic game detection
- Automatic clip organization into folders by game
- Separate desktop audio and microphone audio tracks
- AV1 recording support
- Configurable recording quality, resolution, FPS, and bitrate
- Customizable hotkeys
- Recent clips gallery
- Built-in lightweight clip player
- Quickly browse and play recent recordings
- Recording status notifications
- Slide-in and slide-out notification animations
- Automatic folder creation for newly detected games
- Lightweight Windows interface designed to stay out of the way while gaming
